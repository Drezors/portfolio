# Portfolio Next.js

Ce projet est un portfolio développé avec [Next.js](https://nextjs.org/), initialisé avec `create-next-app`.

---

## ⚠️ Statut du projet

Le projet est **en cours de développement (WIP)** et **n’a pas encore été déployé**.

En raison d’un délai de rendu annoncé tardivement, le développement n’a pas pu être entièrement finalisé ni déployé en production.  
Cependant, une version fonctionnelle est disponible en local afin de permettre la consultation du portfolio.

---

## Lancer le projet en local

### 1. Installer les dépendances

```bash
npm install
```

### 2. Lancer en mode développement

```bash
npm run dev
```

Puis ouvrir : [http://localhost:3000](http://localhost:3000)

### 3. Lancer en mode production (après build)

```bash
npm run build
npm start
```
